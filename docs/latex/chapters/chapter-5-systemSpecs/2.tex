\section{Nem funkcionális követelmények}

\begin{itemize}
    \item Az alkalmazás webes felületen érhető el, ezért a használatához modern, JavaScript futtatását támogató böngésző szükséges.
    \item A filmek kereséséhez, a filmrészletek betöltéséhez, valamint a felhasználói listák kezeléséhez folyamatos internetkapcsolat szükséges.
    \item A filmek böngészése és a filmrészletek megtekintése regisztráció nélkül is elérhető.
    \item A watchlist, a megnézett filmek listája, az értékelés és a profiloldal használatához regisztrált felhasználói fiók szükséges.
    \item A regisztráció e-mail cím és jelszó megadásával történik, a fiók aktiválásához pedig az e-mail cím megerősítése szükséges.
    \item A bejelentkezett állapot fenntartásához a böngészőnek kezelnie kell a munkamenethez szükséges sütiket.
    \item A filmadatok külső filmes adatforrásból érkeznek, ezért a rendszer működéséhez a TMDB API elérhetősége és megfelelő szerveroldali API-kulcs szükséges.
    \item A felhasználói adatok tárolása Supabase adatbázisban történik, ezért az autentikációhoz és a személyes listák kezeléséhez a Supabase szolgáltatás elérhetősége szükséges.
    \item Az alkalmazás használatához nincs szükség külön telepített kliensprogramra vagy speciális hardverre; elegendő egy internetkapcsolattal rendelkező eszköz és egy böngésző.
\end{itemize}
