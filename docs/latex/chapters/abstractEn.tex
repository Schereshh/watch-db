Nowadays, web applications have become extremely widespread and are used on a daily basis, whether for work, communication, or entertainment. This significant growth in the use of web applications is due to the fact that an application accessible from a browser can come very close to the level and functionality of desktop software.

Behind modern web applications there are numerous planning steps, decisions, development tasks, as well as technical or even financial obstacles, whose solution and implementation are the responsibility of a team. Each member has a defined role, from forming the initial idea and designing the UI (user interface) to development and maintenance.

This thesis aims to present the planning processes of such a web application: how an idea can evolve into a finished product, and what processes take place before developers write even a single line of code or UX designers draw even one line.

To demonstrate this, the thesis presents a “fictional” development team that plans and develops a movie logging web application.

\textbf{Keywords}: web applications, planning, development, UX design, movie logging
